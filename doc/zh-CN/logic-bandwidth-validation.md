# 逻辑分析频率实测

2026-10-21，当前 RP2040 固件验证通过的最高 SUMP 档位为 **50 MS/s**。
三条载板通路重复检查全部通过的最高输入频率为 **15.625 MHz**。
更高频率有时能读对，也会漏脉冲、混叠，不能作为跨采样相位可靠的上限。

## 夹具与通过标准

- Debug 序列号 `YOUR_SERIAL`，保留现有优化固件和默认 125 MHz 时钟；未改固件或时钟配置。
- Work 使用现有 `harness-terminal`，在 GP5、GP10、GP26 输出 PWM，分别观察 SUMP 通道 3、7、2。
  Work 报告系统时钟为 125 MHz。参考值使用 PWM 回复中的实际频率；请求频率可能因周期取整而变化。
- 无触发立即采样，16 路、输入同步器开启，每次 32,768 点。停止 `phd`，直接读取 LA CDC。
- 根据上升沿间距计算的频率误差不超过 0.2%，且最大上升沿间距不超过
  `ceil(采样率 / 参考频率) + 1` 个样本，同时检查返回长度和未使用的高位。

测量的是当前载板的数字边沿/频率捕获能力，不是模拟带宽，也没有外部仪器校准时基。
频率检查通过不代表极限附近的脉宽和占空比仍能精确测量。

## 采样率

用 100 kHz 参考 PWM 校验，每档采集五次：

| SUMP 请求采样率 | 结果 |
| --- | --- |
| 1、2、5、10、20、25 MS/s | 参考频率正确，各 5/5 |
| 33.333 MS/s | PIO 分频后为 33.299 MS/s，参考正确，5/5 |
| 50 MS/s | 参考频率正确，5/5 |
| 100 MS/s | 100 kHz 被读成 160 kHz，0/5 |

100 MS/s 档中，100 kHz 每周期约占 625 个样本，而非应有的 1000 个。
由此反推平均有效采样率约 62.5 MS/s，但客户端时间轴仍按 100 MS/s 解释。
另用 1 MHz 参考交叉检查，也被读成约 1.6 MHz。因此，返回完整 32K 样本不等于采样时序正确。

这一表现符合 PIO/DMA 吞吐不足导致采样停顿的情况。SUMP 不回传采样器错误标记，本轮证明了时间轴失真，
没有直接读取 RXSTALL 来确诊根因。当前 SUMP 分频档位从 50 跳到 100 MS/s，不能选择 62.5 MS/s。

## 50 MS/s 下的输入频率

每个边界频点在三条通路各抓五次：

| 实际 PWM 输入 | GP5/GP10/GP26 合计通过次数 |
| --- | ---: |
| 12.500 MHz | 15/15 |
| 15.625 MHz | 15/15 |
| 17.857 MHz | 2/15 |
| 20.833 MHz | 6/15 |
| 25.000 MHz | 9/15 |
| 31.250 MHz | 0/15 |

对 15.625 MHz 单独复核，三条通路均为 **30/30，合计 90/90**。
读得频率为 15.624809–15.625382 MHz，最大相对误差 0.002442%；上升沿间距为 2–4 个样本，没有长周期缺口。
该频点的 PWM 每周期恰为 8 个 Work 时钟，占空比恰为 50%；其他奇数周期频点的占空比会取整。

更高频率的通过次数并非单调，反映了采样相位的影响。例如部分 25 MHz 能恰好读成 25 MHz，
另一些却成为恒高或大量丢周期，不能据此宣称可靠支持 25 MHz。
15.625 MHz 的采样高电平比例也在 50%–62.5% 之间，说明频率正确时脉宽分辨率仍然有限。

这是三条通路的有限次测量，采集之间有回传间隔；没有确定 15.625–17.857 MHz 之间的精确截止点，
也未验证所有载板引脚、边沿触发模式、RP2350 或长时间运行。

## 复现与记录

先停止 `phd`，使用已运行 `harness-terminal` 的专用夹具，显式选择序列号。
工具结束会停止所选 PWM 并恢复 Work 初始电源，不烧录固件：

```sh
PYTHONPATH=host python3 host/tools/check_logic_bandwidth.py \
  --serial YOUR_SERIAL --pin 5 --rates --repeats 5 \
  --signal-hz 12500000 15625000 17857143 20833333 25000000 31250000 \
  --output BUILD/logic-bandwidth/gp5.json
```

将 `--pin` 改为 10、26 可复现另外两条通路；各通路使用
`--signal-hz 15625000 --repeats 30` 可复现确认测量。
默认 SUMP divider 为 1，即 50 MS/s；`--divider 0` 可单独测试有时序失真的 100 MS/s 档。

JSON 保存每次的频率、占空比、边沿/连续电平长度分布和原始文件路径。
二进制文件保留全部 32 位小端样本。`ok` 仅表示测量流程完成；极限扫描预期包含失败频点，
各次是否通过应看 `frequency_ok`、`period_ok`。

本地记录位于忽略的 `BUILD/logic-bandwidth/`：`sweep-50m.json`、`boundary.json`、
`confirmed.json`、`reproduce-tool.json`；原始波形位于 `boundary/` 和 `reproduce-tool/raw/`。
1 MHz 参考的交叉检查保存在 `sweep-initial.json`。
Work 起始断电，结束恢复断电，三路测试 PWM 均已停止；Debug 和 Work 固件均未重新烧录。
