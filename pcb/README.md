# PCB hardware designs

The only current hardware is the Pico Dualcore Devboard v1.2
(`pcb/pico-dualcore-devboard-v1.2/`).

- `dualcore` — stable entry pointing at the current design directory, used by
  firmware and documentation.

Hardware revisions are maintained only in this directory; firmware board
names, build artifacts and device identifiers carry no hardware revision
suffix.
